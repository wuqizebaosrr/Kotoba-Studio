# Kotoba Studio

一个面向 Windows 的开源桌面 Galgame 制作工作台。通过可视化剧情块组织对白、旁白、角色、场景和分支，边编辑边预览，并导出可独立运行的游戏。

当前版本：**0.9.3**。界面使用 HTML、CSS 和原生 JavaScript，桌面运行环境使用 Electron。启动编辑器不需要 Web 服务器；除主动使用 API 辅助外，编辑与游戏运行均可离线完成。

## 开始使用

### 普通用户

如果本仓库的 **Releases** 已提供 Windows 安装包，下载 `Kotoba-Studio-版本号-Windows-x64-Setup.exe` 后运行。不要将 GitHub 的源码 ZIP 当成安装包。

没有安装包时，可按下面的源码运行步骤启动。

### 从源码运行

需要 Windows x64、Node.js 24 或更新版本，以及 npm。Node.js 安装说明见 [Node.js 官网](https://nodejs.org/)。

1. 下载本仓库的源码 ZIP 并解压，或用 Git 克隆。
2. 在包含 `package.json` 的目录打开终端。
3. 执行：

```sh
npm ci
npm start
```

首次安装依赖和启动需要网络，以准备 Electron 运行文件；运行环境准备完成后可离线启动。不要直接双击 `dist/index.html`，文件保存、素材导入和打包需要桌面接口。

## 能做什么

- 新建、保存、打开、删除与恢复工程；章节文件夹和滚动位置记忆。
- 对白、旁白、背景、立绘、CG、音乐、特效、选项和跳转剧情块。
- 拖动剧情块排序，拖动分隔条调整剧本与预览两栏宽度。
- 素材批量或文件夹导入、分类、搜索；单文件不超过 20 MB。
- 角色分类、置顶、默认立绘和差分；多人同屏、拖动定位、大小与位移动画。
- 16:9 预览适配，场景切换、字幕布局、纯色与图片背景。
- 画面和立绘抖动、闪光、天气粒子、叠加特效及外部预设。
- 每句配音、音量和等待播放结束；独立背景音乐。
- 文本粘贴和导入、章节识别、角色对应与不明确对白的人工确认。
- 可选 Chat Completions API 辅助整理、描写和设计；建议稿由用户确认采用。
- 导出离线 HTML、Windows 单文件 EXE 或便携游戏；支持 6 个存档位。

完整操作步骤见 **[使用说明](docs/使用说明.md)**。想修改代码或自行生成安装包，见 **[开发与发布](docs/开发与发布.md)**。

## 一个最小制作流程

1. 在「工程」新建工程。
2. 在「素材」导入背景、立绘、音乐和配音，并放入文件夹。
3. 在「角色」创建角色，绑定默认立绘和差分。
4. 在「剧本」创建章节，添加旁白与对白；选中剧情块后编辑右侧属性。
5. 设置场景背景，按需开启多人同屏、分支和特效。
6. 点击「运行预览」检查剧情，再用「打包 EXE」生成成品。

## 数据存放

默认工程库、自动恢复、API 设置和界面偏好保存在当前 Windows 用户的 `%APPDATA%\KotobaStudio`。将工程另存为 `.kotoba.json` 时，图片与音频会嵌入该文件。

若需要自定义数据位置，可在启动前设置 `KOTOBA_DATA_DIR`。这不是必须步骤。自动化桌面检查使用仓库内被忽略的 `artifacts/verification/test-data`，与正式工程分开。

API 密钥不会写入工程或游戏。使用在线接口时，只有用户主动提交的文本以及所选角色名、章节名会发往配置的服务；费用和服务规则以接口提供方为准。

## 检查与构建

```sh
npm run check
npm run scan:public
npm test
npm run test:desktop
npm run build:windows
```

工作台安装包输出到 `releases/`。`build:windows` 当前支持 Windows x64，需要系统 .NET Framework 的 C# 编译工具。游戏成品也可以直接在运行中的工作台里打包。

仓库附带 Windows 检查工作流，以及手动触发的 **Build Windows** 工作流；构建产物下载见该次工作流的 Artifacts。它们使用 [GitHub 官方 Actions](https://github.com/actions)，不需要在仓库里填写个人密钥。

## 仓库结构

| 目录 | 用途 |
| --- | --- |
| `desktop/` | 桌面主进程、文件服务、播放器与打包器 |
| `dist/` | 编辑器界面和共享故事内核的源码，**不是可删除的构建缓存** |
| `tests/` | 单元检查和公开测试文本 |
| `assets/effect-presets/` | 随软件提供的基础特效预设 |
| `docs/` | 使用、开发和发布说明 |
| `scripts/` | 检查、测试和整理发布副本的命令 |

本副本不包含私人剧情、用户素材库、存档、API 配置、个人路径或历史游戏成品。示例角色与场景仅用于演示编辑功能。
