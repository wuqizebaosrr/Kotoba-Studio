# Kotoba Studio 使用说明

## 1. 安装与启动

本软件面向 Windows x64。普通用户使用仓库 Releases 中提供的 Windows 安装包。若只有源码，请安装 Node.js 24，在源码目录执行 `npm ci`，再执行 `npm start`。

初次打开会看到一个包含教室背景和简单立绘的演示工程。它用于熟悉功能；制作自己的游戏时，请先在左侧「工程」新建工程。

## 2. 工程与备份

「工程」可新建、打开、删除和恢复工程。删除会先进入软件回收站。工作台自动保存当前修改；也可使用右上角「保存工程」或 Ctrl+S 保存。

通过文件打开的工程会写回所选文件。Ctrl+Shift+S 可另存副本。完整 `.kotoba.json` 工程含嵌入的图片与音频，适合备份和迁移。保留独立备份，尤其是在批量改稿、清空章节或删除素材前。

## 3. 章节、文件夹与排序

场景目录中的「＋ 文件夹」可新建章节分类，也能建立子文件夹。点击分类查看该分类及子分类里的章节。章节旁的「移」用于移动到其他文件夹；选中某个文件夹后新建场景，会建在该文件夹里。

目录支持独立滚动，底部显示浏览进度。切换章节和分类会保留相应滚动位置。文件夹只负责整理，不改变剧情的跳转关系。

删除文件夹会把章节和子文件夹移到上一级，不会删除剧情。章节旁「清」用于清空该章剧情，垃圾桶用于删除章节；操作前会确认，也可撤销。

## 4. 编辑剧情块

在剧本底部添加对白、旁白、背景切换、分支、CG 或其他块。点击某一块，在右侧属性区编辑。不同类型会显示不同设置。

拖动块左上角的六点把手可调整顺序，绿色线表示插入位置。接近列表边缘会自动滚动。松开后保存新顺序；取消拖动不会改稿。属性区也有上移和下移按钮。

拖动剧本列表与舞台之间的竖向分隔条可调节两栏宽度，双击恢复默认。比例在本机记忆。分隔条获得焦点后，左右方向键也可微调。

撤销可恢复剧情排序、块删除、章节清空等更改。输入文字时，Ctrl+Z 仍按文本编辑的通常方式工作。

## 5. 素材库与文件夹选图

「素材」支持单个、批量和整个文件夹导入。导入文件夹会保留分类层级。图片、音频单文件上限为 20 MB；工程总大小上限为 256 MB。导入结果会说明重复或不支持的文件。

可新建素材文件夹、移动和删除素材。删除被引用的素材后，对应剧情会解除绑定，因此打包前应重新检查背景、立绘、CG 和音频。

场景背景、角色主立绘和差分编辑中的「图片文件夹」直接筛选素材库分类，包含子目录。「按文件夹选择图片」提供缩略图、搜索和翻页。更换筛选分类不会自动清除已绑定的图片。

## 6. 角色与差分

在「角色」添加角色，填写名称，绑定主立绘。推荐用透明背景 PNG。点击「管理差分」为普通、微笑、惊讶等表情或姿势绑定图片，并选择默认差分。

角色可分类、置顶和删除。删除前会显示剧情引用，并提供保留文字为旁白或转交给其他角色的处理方式。

在对白或立绘控制块中选择角色、差分和显示状态。立绘差分也可按其图片所在的素材文件夹查找。

## 7. 多人同屏、位置与位移

剧本工具栏点击「多人同屏」，启用本章并勾选出场角色。角色选择支持角色文件夹、搜索和只看已勾选；切换分类会保留草稿。

可在窗口预览中分别拖动角色，或调节水平位置、脚底位置与大小。支持数值、滑杆以及 0.1%、1%、5% 微调步长。均匀排列可快速安排多人。点击「应用到当前剧情」才保存，取消会丢弃窗口草稿。

例如：角色前一句在水平 20%，后一句改到 70%，并设置位移时长 600 毫秒。从前一句试演并继续，就会在 0.6 秒内移动到新位置。可选择匀速、平滑起止、加速或减速。0 毫秒为直接切换，首次出场直接显示。

单人模式也可在属性区设置位置、大小和位移动画。开启「拖动立绘」后可直接拖动舞台中的目标角色。每个角色独立控制，取消其显示即可离场。

## 8. 场景、CG 与字幕

「场景背景设置」控制整个游戏画面。可选图片、纯色、完整显示或铺满画面，并选择作用于开场、当前剧情之后或全章。铺满可能裁切图片边缘；完整显示会保留边缘。

插入 CG 会覆盖场景背景并暂时隐藏立绘。可以在 CG 上继续对白，再用「隐藏 CG」恢复原场景和角色状态。CG 本身也可选择适配方式。

单句属性区的字幕位置、字号、对齐及位置预设默认只影响当前剧情块，修改时会启用本句独立布局。取消独立布局后恢复工程默认。「全局字幕布局」用于统一调整整部作品。

「字幕框背景」控制字幕框的颜色、图片、透明度和圆角，不是整屏场景背景。其设置适用于整部作品，窗口内会说明作用范围。

预览保持 16:9。在超宽或纵向窗口中会居中留边，立绘、字幕、CG 和特效共用相同坐标。

## 9. 音乐与配音

在素材库导入音频。音乐块用于背景音乐；对白和旁白属性中的配音设置用于单句音频。可以试听、调整音量，并选择是否等待配音结束才允许继续。

切句或退出预览时会停止对应配音。游戏设置分别控制背景音乐与配音音量。浏览器阻止首次音频播放时，按提示点击游戏画面。

## 10. 特效与场景切换

场景可设置交叉淡化、黑场或滑入等切换效果。特效块可加入画面抖动、立绘抖动、闪光、雨雪花瓣、推进、失焦及叠加图片。按需设置时长、强度、颜色和是否自动继续。

基础预设位于源码的 `assets/effect-presets`，工作台安装包中位于 `特效预设`。可通过外部预设导入、导出复用设置；图片叠加效果使用素材库中的图片或 GIF。

## 11. 选项分支与流程

「设计分支」可填写选项并指定目标章节，也可创建独立分支章节。流程页可查看关系并定位源剧情块。

选择目标时，空目标表示结束故事。删除章节后，指向它的跳转会按确认提示处理。打包前会检查不存在的目标。

## 12. 文本转换与 API

在文本转换页直接粘贴或导入 TXT，再点「识别并预览」。支持章节标题、角色对白、旁白和已有指令。

建议使用明确格式：

```text
# 序章
旁白：窗外的雨停了。
林澪：现在可以出发了吗？
我：走吧。
```

先在角色管理中创建同名角色。识别以唯一完整名称或手动对应为依据，不会自行轮流分配说话人。不明确的引号对白需要人工逐句确认。写入前可选择更新已有章节、新建章节、追加或替换内容。

API 辅助为可选功能。填写兼容 Chat Completions 的地址和模型名，按服务需要提供密钥。Windows 上可选择加密保存；密钥不进入工程和游戏。只在主动提交后调用接口，建议稿不会自动修改原文或工程，必须检查并采用。在线接口可能收费。

## 13. 游戏菜单、预览和存读档

「游戏进入菜单」可设置标题、副标题、背景图片或纯色、文字颜色，并预览。导出游戏提供开始、继续、读取、设置和退出。

「运行预览」可从章节开场试演，也可从选中的块试演。点击画面、空格或右方向键推进；Esc 退出工作台试演。导出游戏支持 F11 全屏。

游戏提供 6 个存档位。存读档窗口顶部有「取消」，底部有固定返回按钮；中间列表可独立滚动。取消或 Esc 返回打开它之前的游戏、标题或设置画面，取消本身不执行保存或读取。

存档在当前设备上，与制作工程分开。导出 HTML 的进度依赖浏览器本地存储，清理浏览器数据后可能丢失。Windows 成品按工程标识保存进度。

## 14. 导出成品

设置页可导出离线 HTML。交付时把生成的 HTML 文件给玩家即可，图片和音频包含在其中。玩家用浏览器打开，首次播放音频可能需要点击。

右上角「打包 EXE」可生成 Windows 单文件 EXE 或便携文件夹。选择成品输出目录后等待完成。

- 单文件 EXE 可以单独复制；首次启动会准备运行文件。
- 便携格式必须完整复制整个文件夹，运行 `GamePlayer.exe`。
- 成品只包含播放器、剧情和游戏素材，不包含工作台工程库与 API 密钥。

单文件打包依赖 Windows 系统中的 .NET Framework C# 编译工具；缺少时可先用便携格式。打包出现角色、CG、背景或跳转缺失时，按提示修复后重新导出。

## 15. 常见问题

**源码解压后没有 EXE？** 源码不是安装包。使用 Releases 中提供的 EXE，或按本文第一节运行源码。

**找不到自己的工程？** 默认数据在 `%APPDATA%\KotobaStudio`；另存的 `.kotoba.json` 在你选择的位置。此公开副本不包含他人的工程。

**改一句旁白时其他旁白也移动？** 在当前句属性里修改布局。若打开「全局字幕布局」，改变的是所有沿用默认布局的剧情块。

**预览图片边缘不全？** 检查背景或 CG 的完整显示 / 铺满设置。舞台保持 16:9，图片自身比例不同可能留边或被裁切。

**素材或工程太大？** 单文件上限 20 MB，工程上限 256 MB。可压缩音频、减少大图或拆分制作工程后再导入。

**准备把自己的游戏发给别人？** 先检查所有分支、配音和存读档，并确认所用素材可用于你的发布用途。
